# VaultKey Password Generator

A polished desktop app that generates strong, random passwords using Python's secure `secrets` module.

## Run

```powershell
py password_generator.py
```

Or double-click `run_password_generator.bat` in File Explorer.

Use the slider to choose a length, select the character types you want, and click **Generate**. Use **Copy password** to put it on your clipboard.

## Requirements

- Python 3 with Tkinter (included with standard Windows Python installations)
