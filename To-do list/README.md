# TaskFlow To-Do List

A simple desktop to-do list application written in Python using the built-in Tkinter GUI toolkit.

## Features

- Add, edit, and delete tasks
- Mark tasks complete (or return them to active)
- Set categories, priorities, and optional due dates
- Search tasks and filter by active/completed status
- Tasks are saved automatically in `tasks.json`

## Run

Python 3 is the only requirement.

Double-click `run_todo.bat`, or run:

```powershell
python todo_app.py
```

If Windows says Python cannot be found, install Python 3 from [python.org](https://www.python.org/downloads/) and select **Add Python to PATH** during installation. Tkinter is included with the standard installer.

Double-click a task to mark it complete. Select a task to load it into the editor.
